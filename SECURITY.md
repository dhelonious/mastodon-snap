# Security Policy

## Supported versions

Only the latest release is supported.

Security updates affecting the base container dependencies of the Snap are usually provided by rebuilding the latest release. A new version will be published to incorporate updates to Mastodon or its dependencies.

## Reporting a vulnerability

If you discover a security vulnerability, please report it via [GitHub Private Vulnerability Reporting](https://github.com/dhelonious/mastodon-snap/security/advisories) as soon as possible.

Please include the following:
- A detailed description of the issue.
- Steps to reproduce or test it.
- The affected version.
- Any suggested mitigations or fixes.

Reports will be reviewed as soon as practical. Confirmed vulnerabilities will be addressed in a future release.

Please only report issues that have a demonstrable security impact. General bugs, questions, and feature requests should be reported via the standard [issue tracker](https://github.com/dhelonious/mastodon-snap/issues).
